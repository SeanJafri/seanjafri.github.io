# seanjafri.github.io

Portfolio site for **Sean Jafri** — robotics hardware engineer (robotic test
fixtures, mechatronics, design-for-cost). Live at https://seanjafri.github.io/,
served by GitHub Pages from the `portfolio-v2` branch.

## Structure
- `index.html` — single-page site (intro, selected work, process, contact)
- `js/projects-data.js` — all project card content (edit projects here)
- `js/tooltips-data.js` — hover-term definitions
- `js/main.js` — modal, tooltip, and reveal behavior
- `css/main.css` — design tokens and styles
- `img/` — project photos and video stills · `sean_jafri_resume.pdf` — current resume
- `legacy/` — the original 2017 portfolio, preserved as-is

## Editing content
Project text lives in `js/projects-data.js`; tooltip definitions in
`js/tooltips-data.js`. No build step — edit, commit, and GitHub Pages
redeploys in a minute or two.
